# @tiklive/core

Internal workspace package. It holds the TikTok LIVE connector, and it is bundled into the published `tiklive`
package as `tiklive/core` (and `tiklive/testing` for the fakes). Don't install it on its own.

It is private, so it isn't published. For the public API, see [docs/user/library.md](../../docs/user/library.md).
