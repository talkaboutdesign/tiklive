# @tiklive/client

Internal workspace package. It holds the dependency-free browser and Node client, and it is bundled into the
published `tiklive` package as `tiklive/client` and `tiklive/tiklive.js`. Don't install it on its own.

It is private, so it isn't published. For the public API, see [docs/user/library.md](../../docs/user/library.md).
